# TecnoSoluciones - Sitio Web Corporativo

Sitio web corporativo y portafolio desarrollado para **TecnoSoluciones**, enfocado en ofrecer servicios de transformación digital, desarrollo de software a medida y diseño web de alto impacto.

---

## 🚀 Características

- **Diseño Adaptable (Responsive):** Totalmente optimizado para dispositivos móviles, tablets y computadoras de escritorio mediante el sistema de rejillas de Bootstrap 5.
- **Navegación Fluida:** Barra de navegación principal integrada con enlaces a todas las secciones esenciales.
- **Galería Dinámica:** Componente de carrusel interactivo que muestra las instalaciones, entorno de trabajo y enfoque técnico.
- **Estructura Semántica:** Construcción limpia cumpliendo con los estándares modernos de HTML5 y accesibilidad básica.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración del contenido.
- **CSS3:** Estilos personalizados (`./styles/styles.css`).
- **Bootstrap v5.3.3:** Framework para componentes y diseño responsive.
- **Unsplash:** Fotografías e imágenes de alta resolución.

---

## 📁 Estructura del Proyecto

```text
.
├── index.html              # Página principal (Inicio)
├── pages/                  # Secciones del sitio
│   ├── sobre-mi.html       # Información sobre la trayectoria
│   ├── servicios.html       # Catálogo de servicios
│   ├── proyectos.html       # Portafolio de trabajos realizados
│   ├── faq.html             # Preguntas frecuentes
│   └── contacto.html        # Formulario e información de contacto
└── styles/
    └── styles.css          # Estilos CSS personalizados
```

---

## 💻 Instalación y Ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/tecnosoluciones.git
   ```

2. **Abrir el proyecto:**
   - Navega hasta la carpeta del proyecto.
   - Abre el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Mozilla Firefox, Edge, etc.).
   - *Tip:* Si utilizas Visual Studio Code, puedes hacer clic derecho sobre `index.html` y seleccionar **Open with Live Server**.
